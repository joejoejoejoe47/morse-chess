# Sandbox menu media (MasterGus goblin Sandbox)

Used by the goblin project `proj_mastergus_sandbox_setup` (https://alltherex.com/goblin/?id=proj_mastergus_sandbox_setup&play=true).

- `bg/` page backgrounds (1920x1080), `btn/` button skins (labels baked in), `tr/` transition clips (1280x720 H.264, no audio).
- All art is original: backgrounds, crest, boards, planks, chains, doors, halls and portraits were generated for Morse Chess with the
  Grok Bot image tool, then composited and lettered in code (Cinzel / Cinzel Decorative / EB Garamond, SIL Open Font License).
- Transitions are rendered frame-by-frame from that art (no third-party footage).
- Layout idea (crest at top, boards hanging on chains, board swap on a chain) is inspired by the classic chess-battle menu style; no
  assets, logos or footage from any existing game are included.
